# ADR 0002: 실패 시 LOCAL로 수렴하는 입력 계약

- 상태: Accepted
- 책임자: cherr

## 맥락

네트워크 입력 공유에서 가장 큰 위험은 기능 부족이 아니라 source 입력이 막히거나 destination에 키가 눌린 채 남는 것이다. 정상 경로보다 실패 경로가 제품의 신뢰도를 결정한다.

## 결정

- destination 준비가 확인되기 전에는 source 입력을 억제하지 않는다.
- 활성 제어권은 하나이며 세션과 epoch에 묶는다.
- 연결 단절, 절전, 잠금, 프로세스 종료와 상태 불일치에서 기존 제어권을 폐기한다.
- 양쪽은 가능한 범위에서 `ReleaseAll`을 수행하고 `LOCAL`로 수렴한다.
- 재연결은 새 세션이며 기존 lease나 불확실한 입력을 재개하지 않는다.
- destination의 물리 로컬 입력은 원격 입력보다 우선한다.

## 결과

일부 입력이 전달되지 않는 실패는 허용하지만, 사용자를 입력에서 가두거나 불확실한 입력을 재생하는 실패는 허용하지 않는다. 이 계약은 상태 모델, protocol, Windows adapter, 진단과 테스트의 공통 기준이다.

## 검증

Phase 0에서 프로세스 강제 종료, 네트워크 단절, 절전, 잠금과 합성 입력 재진입을 실제 대상 장비로 검증한다. 구체적인 지연과 반복 횟수는 측정 전에 고정하지 않는다.
