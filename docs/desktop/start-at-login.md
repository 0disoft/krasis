# Windows 시작 시 실행

앱 아래쪽의 체크박스로 켜고 끈다. 최초 기본값은 켜짐이다.
로그인 후 사용자 계정의 Run 항목이 고정 복구 CLI를 실행하고,
검증된 마지막 Krasis 버전을 트레이에서 시작한다. 업데이트 뒤에도
등록 경로는 유지되며, 보호 입력 서비스의 시작 설정은 변경하지 않는다.

마지막 연결 상대의 별칭과 fingerprint를 사용자 전용 파일에 저장한다.
로그인 시작에서 현재 페어링 정보가 둘 다 일치하고 에이전트가 LOCAL인 경우에만
연결을 요청한다. UI에서 연결 해제를 누르면 저장된 복구 상대를 지운다.
로그인 전 Windows 잠금 화면에서 관리 앱을 실행하지 않는다.

등록 실패는 설정 화면에 표시한다. 설정 저장에 실패하면 이전 Run 설정으로
복원한다. 해제한 옵션은 버전 갱신 후에도 유지한다.
