# Windows x64 두 PC 수동 테스트: 시작 준비

이 묶음은 설치 프로그램이나 코드 서명된 정식 릴리스가 아닌 개발 테스트용이다.
Windows x64에서 직접 검증하기 위한 것이며 모든 Windows 버전의 호환성을 보장하지 않는다.
Go나 C 컴파일러를 테스트 PC에 설치할 필요는 없다. 포함 파일은 CLI, 에이전트, 연결 관리 GUI,
이 안내, BUILD.json과 SHA256SUMS.txt뿐이다. 장비 키나 토큰은 포함하지 않는다.

## 1. 두 PC에 준비

두 PC에 같은 ZIP을 복사하고 각각 새 폴더에 압축을 푼다. ZIP 안에서 직접 실행하지 않는다.
기존 Phase 0 launcher/lab 묶음과 섞지 않는다. 두 PC를 A와 B로 구분한다.
실행 전 전송받은 ZIP의 SHA-256을 빌드 시 안내받은 값과 비교한다.
PowerShell에서 `Get-FileHash .\krasis-windows-x64-smoke.zip -Algorithm SHA256`으로 확인할 수 있다.
SHA256SUMS.txt는 압축 해제된 파일의 손상 확인용이며 코드 서명 대신은 아니다.

서명되지 않은 프로그램 경고나 조직 보안 정책으로 실행이 차단되면 차단 내용을 확인한다.
Defender, SmartScreen, 조직 정책을 끄지 않는다. 이 단계에서 관리자 권한은 사용하지 않는다.

## 2. 에이전트만 실행

각 PC에서 압축을 푼 폴더를 PowerShell로 열고 다음을 실행한다.

```powershell
.\krasis-agent.exe
```

창이 별도 메시지 없이 실행 상태로 남아 있을 수 있다. 해당 창을 유지한 채 같은 폴더에서
새 PowerShell 창을 열고 다음 명령을 실행한다.

```powershell
.\krasis.exe status
```

처음 실행이라면 상태가 `LOCAL`인지 확인한다. 에이전트를 중지하려면 에이전트 창에서 Ctrl+C를
누른다. 최초 실행은 `%LOCALAPPDATA%\Krasis`에 해당 PC의 기기 신원과 로컬 제어 파일을 만든다.
이 폴더, 키, 토큰, 인증서 저장소를 다른 PC로 복사하거나 공유하지 않는다. 종료해도 기기 신원과
신뢰 정보는 남는다. 이전 실험 기록이 있다면 파일을 임의 삭제해 초기화하지 않는다.

## 3. 연결 전 확인하고 멈추기

이미 페어링·연결 설정을 끝낸 장비는 에이전트 실행 후 `krasis-control.exe`를 더블클릭하면 된다.
기기 목록에서 상대를 선택하고 `연결` 또는 `연결 해제`를 누른다. 상태는 주기적으로 갱신된다.
창을 닫아도 에이전트나 연결은 종료되지 않는다. 종료 전 `연결 해제`를 사용한다.
이 첫 GUI는 에이전트를 자동 실행하거나 최초 페어링·배치 설정·기기 자동 발견을 수행하지 않는다.
새 ZIP으로 교체할 때 기존 GUI와 에이전트를 먼저 종료하고 새 폴더에 푼다.
기존 `%LOCALAPPDATA%\Krasis`는 유지하므로 페어링·연결 설정을 다시 입력할 필요가 없다.

각 PC에서 `ipconfig`로 Wi-Fi 어댑터의 IPv4 주소를 확인한다. 두 PC의 `status` 결과,
Wi-Fi IPv4 주소, B가 A의 왼쪽/오른쪽 중 어디에 놓였는지를 확인한 뒤 페어링을 진행한다.
이 단계에서는 `pair listen`, `pair dial`, `connect`를 실행하지 않는다.
같은 Wi-Fi 이름이나 대역이어도 AP isolation 또는 게스트 네트워크 정책으로 통신이 막힐 수 있다.

다음 단계는 제품 페어링 흐름에 따라 명시적 포트 선택, 양쪽 사용자 확인, 연결 설정을 수행한다.
방화벽 규칙·자동 시작·서비스 등록은 이 묶음이 변경하지 않는다.
실제 입력 시험 전 두 PC의 에이전트를 중지할 수 있는지 먼저 확인한다.
첫 입력 시험에는 관리자 앱이나 잠금 화면을 사용하지 않는다.

## 검증 범위

빌드 단계는 Windows x64 PE 형식과 CLI의 인자 없는 usage 종료를 확인한다.
에이전트·네이티브 입력·페어링을 자동 실행하지 않는다. 실기기에서의 입력 전송, 입력 해제,
관리자 앱, secure desktop, 절전 복귀는 별도 수동 검증 대상이다.
