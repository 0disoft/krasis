## 별도로 발견한 자동 복구 실패

A의 자동 복구 예약 작업은 ENABLED이나 마지막 receipt는 settings_unavailable이었다.
설정 읽기가 PrepareLaunch를 호출해 DELETE/WRITE_DAC 권한을 요청한다. 예약 CLI가
launch 폴더를 working directory로 사용하는 상황과 같은, delete sharing 없는 디렉터리
핸들을 잡은 Windows 회귀 테스트에서 설정 읽기 실패를 재현했다. 읽기 전용 디렉터리
핸들로 변경한 뒤 설정·resume·recovery pause 읽기가 모두 성공했다.

g191은 설정 조회 시 디렉터리 생성·삭제 권한 요청을 제거하며 파일 ACL·링크 검사·
크기 제한·strict JSON 검사를 유지한다. 실행 중인 g190이나 두 기기 연결을 이 분석에서
교체하지 않았다. 실제 예약 작업의 g191 성공과 종료 후 자동 복구는 적용 뒤 확인한다.
B에서는 오래된 업데이트 폴더 103개를 정리한 completed receipt도 수신했다.
