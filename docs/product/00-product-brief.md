# 제품 개요

- 상태: Draft
- 제품명: Krasis
- 책임자: cherr

## 한 문장 정의

Krasis는 같은 로컬 네트워크에 있는 두 Windows 노트북을 한 벌의 키보드와 마우스로 오가며 조작하는 로컬 우선 소프트웨어 KVM이다.

## 제품 약속

- 화면 가장자리를 넘어가면 상대 노트북으로 제어권을 넘긴다.
- 원격 입력이 불확실하거나 연결이 끊기면 로컬 입력을 즉시 되살린다.
- 화면, 클립보드, 파일, 키 입력 원문을 클라우드로 보내거나 보관하지 않는다.
- GUI가 꺼져도 입력 agent와 CLI의 안전 계약은 흔들리지 않는다.

## 첫 사용자

집과 스터디카페에 각각 두 대의 Windows 노트북을 두고, 장소별 두 대를 좌우 한 쌍으로 사용하는 단일 사용자다.

## 아직 제품 약속이 아닌 것

- Windows 11 x64만 지원할지
- 설치와 방화벽 설정에 관리자 권한을 요구할지
- 키나 마우스 버튼을 누른 상태의 경계 전환을 허용할지
- 공용 Wi-Fi의 클라이언트 격리를 우회하기 위한 핫스팟 또는 개인 공유기를 운영 조건으로 둘지

이 항목들은 `docs/product/02-spec.md`의 미결정 사항과 Phase 0 검증으로 확정한다.
