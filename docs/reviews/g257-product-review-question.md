## 특히 살펴볼 부분

1. **설치·업데이트·프로세스 수명:** 실행 중 설치, UI·에이전트·서비스 버전 불일치, 동시 설치·갱신·자동 복구, 오래된 endpoint, 부분 실패, 권한 요청 취소, rollback과 다음 실행 복구. UI를 교체할 때 입력 연결을 불필요하게 끊거나 이전 UI가 새 버전을 가로채는 다른 경로가 있는지도 확인해 주세요.

4. **신뢰·권한·배포:** mTLS, 기기 신뢰 취소, 로컬 API, 보호 입력 서비스 경계, 파일·경로 검증, 배포 서명과 자동 업데이트. SHA-256 일치를 배포자 신원 검증으로 취급하지 마세요. 해시나 ACL 검사를 없애거나 관리자 권한을 상시 확대하는 우회책 대신 현재 신뢰 모델에 맞는 수정안을 제시하세요.
