# Krasis 입력 경로 시험

이 프로그램은 Krasis 연결 없이 B에서만 Esc를 한 번 보내는 독립 실험입니다.
`inputInjectionBrokered` 권한이 있는 MSIX 패키지로 실행해야 합니다. 일반
EXE로 실행하거나 패키지 설치가 실패한 경우, 입력 API를 사용할 수 없습니다.

시험용 패키지는 서명 전 상태로 빌드됩니다. 서명되지 않은 패키지는 설치하지
않습니다. 이 저장소는 개발 인증서나 개인키를 포함하지 않습니다. 정식 서명,
설치와 제거 경로가 준비되기 전에는 실제 B에 배포하지 않습니다.

PIN 시험은 기존 g60 관리자 `SendInput` 시험과 별개입니다. PIN은 입력하지
않으며 창을 닫는 Esc만 보냅니다. 관리자 PowerShell 시험에서도 명령을
실행하지 않습니다. 양쪽 모두 B 화면에서 실제 효과를 확인해야 합니다.
